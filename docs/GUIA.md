# Guia del Laboratorio 03: Trabajo Colaborativo

Guia para entender el proyecto del Laboratorio 03, donde usamos Git para trabajar en equipo.

## Objetivo

Documentar el trabajo colaborativo realizado con Git y GitHub.

## Herramientas utilizadas

- **Git** para el control de versiones
- **GitHub** para el repositorio remoto
- **Visual Studio Code** como editor

## Pasos para clonar el proyecto

1. Copiar la direccion desde el boton Code
2. Ejecutar `git clone` con esa direccion
3. Entrar a la carpeta con `cd`
